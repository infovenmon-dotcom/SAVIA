🎁 Regalo de bienvenida Activado: en el primer pedido de cada cliente se añaden gratis la jabonera de bambú y la bolsa de sisal (aparecen en Envíos y en la factura a 0 €).
📦 Coste de embalaje (caja de regalo + lazo) — se resta en el beneficio, una caja por pedido
🎉 Ofertas por categoría Pon un % y toda esa familia se pone en oferta (baja el precio en la web y en el cobro). El correo del domingo la anuncia. Vacío o 0 = sin oferta.

Recuerda pulsar Guardar cambios abajo para aplicarlo.

Producto Precio (€) Antes (€) oferta Coste (€) interno Margen Stock Agotado

• Precio: déjalo en el precio normal o cámbialo.
• Margen: se recalcula solo al tocar el precio, el coste o el descuento de una categoría. Es el margen sobre el precio sin IVA, ya con el descuento aplicado. Mete el coste tal y como lo pagas: con IVA si el proveedor no factura, neto si sí lo hace.
• Antes: para una oferta, pon aquí el precio anterior (mayor que el actual). Se mostrará tachado con el % de descuento. Vacío = sin oferta.
• Stock: vacío = no se controla; un número se irá descontando con cada venta; al llegar a 0 ese producto se vende en Amazon.
• Agotado: fuerza "Comprar en Amazon" sin tocar el stock.

🧪 Herramientas de prueba

Resetea un cliente para volver a probar el regalo de bienvenida (borra la marca de "ya recibido", el contador de pedidos y su último pedido). Úsalo solo para pruebas.

➕ Envío manual / muestra

Crea un envío sin venta (muestras, regalos, prensa/influencers, reposiciones). Metes los datos a mano, descuenta stock y genera la etiqueta CTT. El coste (productos + envío) se refleja como gasto real en el Beneficio; no suma ingresos.

Productos

📦 Envíos (CTT Express)

Pedidos pagados listos para expedir. Crea la etiqueta en el portal de CTT (o descarga el CSV para hacerlo en lote), pega el nº de seguimiento y avisa al cliente con un clic.

Cuando estén configuradas las credenciales de la API de CTT, aparecerá el botón 🏷️ Crear etiqueta CTT en cada pedido: genera el envío, saca la etiqueta térmica y avisa al cliente automáticamente. Mientras tanto, usa Copiar datos / CSV con el portal de CTT.

📊 Centro de cuentas

Ventas, comisiones de Stripe, IVA y neto de un periodo. Para tu control y para tu gestor (exporta a CSV).

El IVA se calcula al 21% sobre el total (los precios ya incluyen IVA). Confírmalo con tu gestor; algunos productos podrían tener otro tipo.

💰 Beneficio real

Documento interno. Calcula tu beneficio: ventas (sin IVA) − coste de lo vendido − comisiones de Stripe. El coste de cada producto se pone en la pestaña "Productos".

El "IVA soportado" es el IVA de tus compras/gastos del periodo (lo pones tú; tu gestor lo afina). "IVA a ingresar" ≈ IVA de ventas − IVA soportado. El margen no descuenta gastos generales ni impuesto de sociedades.

🧾 Facturas

Facturas generadas automáticamente por cada pedido (con los datos de la empresa). Ábrelas para imprimir o guardar en PDF.

Factura simplificada (no certificada). Para facturación legal completa, usa una herramienta certificada cuando lo necesites.

📈 Embudo de compra

Cuántos clientes pasan por cada paso, separado en móvil y ordenador, para ver dónde se quedan. Es anónimo: no usa cookies ni datos personales. Empieza a contar desde que se publica este cambio.
