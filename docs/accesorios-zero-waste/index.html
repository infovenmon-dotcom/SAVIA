Cómo elegir

  • Para la ducha, una jabonera de bambú o la jabonera trío si usas varias pastillas.
  • Para viajar, la bolsa de sisal o un neceser.
  • Para el baño diario, el cepillo de dientes de bambú y el cepillo de pelo de madera.

Cómo se usa

Deja que la jabonera se seque entre usos y límpiala de vez en cuando con agua. Las piezas de bambú y madera duran más si no se quedan en agua.

Preguntas frecuentes

¿Por qué una jabonera con drenaje?

Porque un jabón o un champú sólido que se queda en agua se ablanda y se gasta mucho antes.

¿Qué necesito para empezar con la cosmética sólida?

Una jabonera con drenaje es lo básico: sirve para jabones, champús y acondicionadores sólidos.

¿El bambú se estropea con el agua?

Aguanta bien la humedad, pero dura más si se seca entre usos.
